Before you install

  • Installation needs Jira Cloud admin permission.
  • Review the app permissions on the Atlassian install screen.
  • Check the Security & Trust page for data-flow details.
  • Decide who should run setup and who can create, edit, send, delete, and report.
  • Decide whether to enable optional Mailgun or SendGrid quote email sending.
